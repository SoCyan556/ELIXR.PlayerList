# ELIXR Player List 0.1.2

- Adds first-use registration for the admin Population count. After a successful VRChat sign-in, the tool sends only your own VRChat user ID to ELIXR, once. It does not send passwords, cookies, player rosters, worlds, or ongoing activity.
- Repeat sign-ins, devices, and reinstalls do not add extra users. Offline registration retries at the next sign-in without blocking the app.
- Updated login and privacy disclosures. UI previews and smoke tests do not register users.
- Includes the same self-contained .NET application and offline WebView2 prerequisite installer as 0.1.1.

Counts start with this version; older tool usage cannot be reconstructed. Registration is client-reported and is not proof of VRChat account ownership or authorization.
