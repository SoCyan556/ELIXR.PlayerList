# ELIXR Player List 0.1.3

- Added a desktop Search tab for VRChat display names, independent of the current instance.
- Select a search result to check the existing FewTags, ETags, and public group tag sources. Reuses full/compact indicators, tag colors and animations, profile details, and group-code copying.
- Paginated results, explicit loading/empty/retry states, request cancellation, and VRChat rate-limit handling.
- Searches and results are not saved as history or sent to ELIXR. Sign-in is required; no session cookies are exposed to the frontend.
- Community tags are third-party labels. Private memberships, unavailable sources, and rate limits can leave tag checks incomplete.
